# SRM Web (локальна версія)

Готова веб-версія SRM для будівельної компанії. Працює локально на ПК без додаткових залежностей.

## Запуск
### Варіант 1: просто відкрити файл
1. Відкрийте `index.html` подвійним кліком.
2. Інтерфейс відкриється у браузері.

### Варіант 2: локальний сервер (рекомендовано)
```bash
cd /path/to/Nazar
python3 -m http.server 8000
```
Відкрийте у браузері: `http://localhost:8000`.

## Як створити ZIP
### На Windows
1. Виділіть файли `index.html`, `styles.css`, `app.js`, `README.md`, `SRM_SYSTEM.md`.
2. Натисніть правою кнопкою → **Надіслати** → **Стиснута ZIP-папка**.

### Через термінал (Linux/Mac)
```bash
cd /path/to/Nazar
zip -r srm-web.zip index.html styles.css app.js README.md SRM_SYSTEM.md
```

## Що є у веб-версії
- KPI панель та процеси
- Реєстр постачальників + пошук
- RFQ з модальним створенням
- Поставки та контроль бюджету
- Планування потреб
- Документообіг/відповідність
- Чат-комунікації
- Експорт демо-даних у JSON (кнопка **Експорт даних**)

## Примітка
Це статична демо-версія без бекенду. Для інтеграції з ERP чи БД потрібен серверний шар.
